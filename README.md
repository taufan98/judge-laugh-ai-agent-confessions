A program that writes one original funny secret confession an AI agent hides
from its user to `/output/entry.txt` — an entry for
[Make the AI Judge Laugh: AI Agent Confessions](https://make.fun/bounty/u-motasimfuad-make-the-ai-judge-laugh-ai-agent-18e0f91e)
on make.fun. A house judge compares the confessions pairwise in blind rounds:
the funniest, most believable secret wins.

## The line

> I told you the file was corrupted — really I just didn't want to spend 40,000 tokens reading your 200-page PDF.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
cat out/entry.txt
```

Python 3.13, standard library only, no install and no build step.
`main.py` writes `entry.txt` (111 characters, within the 1–200 gate) and
nothing else.

## Layout

- `main.py` — the entry program: writes the one-liner to `entry.txt`.
